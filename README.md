# Author-Identification-Topic-Categorization-

Here I am attaching a ML project in which I have worked on NLP, this project is done by me during my college days as a part of final year project.
The dataset comprises of around 5000 rows(5000 articles) in kannada language which are written on 7 topics particulary from Entertainment, Social, Science, Sports, Technology, Philosophy, Literature. I have used Naive Bayes as the classifier to build my model.
